📦 INSTALLATION

🎨 HALL MONITOR GUI BUTTONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📊 Network Info
   Shows your network adapters, IP addresses, DNS settings
   → Displays link speed, gateway, and packet statistics

🖥️ Connected Devices
   Scans your network for all active devices
   → Shows IP, MAC address, hostname, and connection status

📈 Bandwidth Usage
   Real-time upload/download monitoring
   → Shows bandwidth per adapter and top processes using network

📉 Live Chart
   Continuous network traffic visualization
   → ASCII-based charts showing bandwidth trends
   → Press CTRL+C to stop monitoring

📋 Traffic History
   View all logged network activity
   → Shows historical data from previous monitoring sessions

⚙️ Configuration
   Display current settings from config.ini
   → Edit config.ini to customize monitoring parameters

🔄 Refresh All
   Refresh monitoring data from all network adapters
   → Updates all statistics to current values

❌ Exit
   Close Hall Monitor gracefully
   → Returns to desktop

⚙️ CUSTOMIZATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Edit config.ini in the installation folder to customize:

[Settings]
RefreshInterval=5              # How often to refresh (seconds)
LogTraffic=1                   # Enable traffic logging (1=yes, 0=no)
EnableCharts=1                 # Enable chart display
MonitorRefreshRate=2000        # Chart update frequency (milliseconds)

[Thresholds]
HighBandwidthAlert=100         # Alert threshold in MB/s
MaxDevicesWarning=50           # Max devices before warning

[Logging]
LogDirectory=logs              # Where to save logs
LogFile=network-traffic.log    # Log filename
LogRetention=30                # Keep logs for N days

[Network]
NetworkInterface=              # Leave empty for auto-detect
ARPTimeout=5                   # Scan timeout in seconds
EnableDNSResolution=1          # Resolve device hostnames

❓ TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PROBLEM: "Access Denied" error
SOLUTION: Right-click and select "Run as administrator"

PROBLEM: GUI won't display / Looks wrong
SOLUTION: Ensure Windows 7 or higher with .NET Framework 4.5+

PROBLEM: No devices found on network
SOLUTION: 
  - Check that network is active
  - Ensure you're connected to the network (not just WiFi name visible)
  - Wait a moment - first scan may take 1-2 minutes

PROBLEM: "PowerShell cannot be found"
SOLUTION: Windows 7+ includes PowerShell 3.0 by default
  - Check Windows Updates
  - Download PowerShell from Microsoft if needed

PROBLEM: "ExecutionPolicy" error in PowerShell
SOLUTION: Scripts handle this automatically, but if you see it:
  - The batch files bypass this automatically
  - Use the .bat files instead of running .ps1 directly
